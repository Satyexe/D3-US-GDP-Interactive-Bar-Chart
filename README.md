# US GDP Bar Chart

A D3.js bar chart of United States GDP over time. Each bar is one quarter. Hover a bar to see the year and quarter.

GDP values come from the [freeCodeCamp GDP dataset](https://raw.githubusercontent.com/freeCodeCamp/ProjectReferenceData/master/GDP-data.json).

## Stack

- HTML
- CSS
- JavaScript
- D3
- Webpack

## Run locally

```bash
npm install
npm start
```

Production build:

```bash
npm run build
```
